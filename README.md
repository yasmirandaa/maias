# Civilização Maia — Site Interativo

Projeto desenvolvido para a disciplina de Artes com o tema Arte Pré-Colombiana.

O objetivo deste projeto é apresentar a Civilização Maia de forma visual, moderna e imersiva, utilizando HTML, CSS e JavaScript puro.

---

## Tema do Projeto

O site aborda:

* contexto histórico da civilização maia
* manifestações artísticas
* materiais e técnicas
* análise do Calendário Maia
* simbolismo
* arte e poder
* legado contemporâneo

O design busca criar uma experiência inspirada em um museu digital interativo, utilizando:

* efeito parallax
* animações suaves
* linha do tempo interativa
* textura de pedra antiga
* cores inspiradas em jade e ouro envelhecido

---
